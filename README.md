# Student Performance Analytics Dashboard

## Overview
A data analytics project built using Python, NumPy, Pandas, and Matplotlib to analyze student academic performance.

## Features
- Student performance analysis
- Grade classification
- Pass/Fail analysis
- KPI reporting
- Dashboard visualization

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib

## Dataset
- 500 student records
- Math, Physics, Chemistry, Attendance

## Output
The dashboard includes:
- Top 20 Students
- Grade Distribution
- Pass vs Fail Analysis
